# Development guide

## Requirements

- Node.js 20+ and npm
- VS Code 1.90+

## Setup

```bash
git clone git@github.com:SeekNHack/PasswdVault.git
cd PasswdVault
npm install
npm run build
```

Open the folder in VS Code and press **F5** (*Run Extension*) to start an Extension Development Host. Use `npm run watch` to rebuild on save.

## Project layout

```
src/
  extension.ts          activation / deactivation
  shared/               types + RPC protocol shared by host and webview
  core/                 vault engine (no vscode dependency, unit-tested)
  host/                 VS Code integration (commands, views, services)
  webview/              dashboard UI (browser code)
test/
  unit/                 vitest suites for src/core
  integration/          tests run inside a real VS Code instance
media/                  icons
scripts/                manifest/wordlist generators
docs/                   documentation
```

## Tests

```bash
npm test                    # unit tests (fast; they use a weak KDF on purpose)
npm run typecheck
npm run test:integration    # downloads VS Code into .vscode-test/ the first time
```

On a headless Linux machine, run the integration tests through `xvfb-run -a npm run test:integration`.

## Manifest

The `contributes` section of `package.json` (commands, menus, settings) is generated by `scripts/write-manifest.cjs`. Edit the script, then run `node scripts/write-manifest.cjs`.

## Release checklist

1. Update the `version` in `package.json` and add an entry to `CHANGELOG.md`.
2. `npm ci && npm run typecheck && npm test && xvfb-run -a npm run test:integration`
3. `npx vsce package` — check the file list it prints (only `dist/`, `media/` and the docs should be included).
4. Install the VSIX locally (`code --install-extension passwdvault-x.y.z.vsix`) and smoke-test: create a vault, add an item, lock/unlock, open the file in KeePassXC.
5. Publish with `npx vsce publish` (requires a Marketplace publisher and a PAT). The `publisher` field (`SeekNHack`) must match your Marketplace publisher ID.
